# 🌷 Personal Website — Zhafira Alfiyya Tabriz

## 📌 Deskripsi

**Personal Website** merupakan website pribadi sederhana yang dibuat menggunakan **HTML dasar** sebagai bagian dari pembelajaran Pemrograman Internet. Website ini berisi informasi mengenai profil diri, data diri, project yang pernah dikerjakan, serta halaman kontak.

Project ini dibuat untuk melatih penggunaan struktur dasar HTML seperti heading, paragraf, navigasi, gambar, tabel, list, hyperlink, dan form.

## ✨ Fitur Website

Website ini terdiri dari beberapa halaman utama:

* **Home** — Halaman utama yang berisi perkenalan singkat dan materi yang sedang dipelajari.
* **About** — Berisi profil singkat, data diri, hobi, dan riwayat pendidikan.
* **Project** — Menampilkan project yang pernah atau sedang dikerjakan beserta teknologi yang digunakan.
* **Contact** — Menyediakan form kontak untuk mengirim pesan.

## 🛠️ Teknologi yang Digunakan

* HTML
* Python
* MySQL
* Git
* Visual Studio Code

> Catatan: Website utamanya dibuat menggunakan **HTML dasar tanpa CSS**.

## 🎯 Tujuan Project

Project ini dibuat sebagai:

1. Pemenuhan tugas mata kuliah **Pemrograman Internet**.
2. Latihan membuat website menggunakan HTML dasar.
3. Media untuk memperkenalkan profil dan project pribadi.
4. Sarana untuk memahami struktur dan elemen dasar dalam pengembangan website.

## 📖 Pembelajaran

Melalui project ini, saya mempelajari beberapa konsep dasar HTML, seperti:

* Struktur dokumen HTML
* Heading dan paragraf
* Hyperlink dan navigasi antarhalaman
* Menampilkan gambar
* Ordered list dan unordered list
* Membuat tabel
* Membuat form
* Input, radio button, checkbox, select, dan textarea

## 🚀 Cara Menjalankan

Karena website ini menggunakan HTML dasar, project dapat dijalankan dengan mudah:

1. Clone atau download repository.
2. Buka folder project menggunakan **Visual Studio Code** atau text editor lainnya.
3. Buka file `home.html`.
4. Jalankan file tersebut menggunakan browser.
